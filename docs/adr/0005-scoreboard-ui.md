# Scoreboard UI direction (not shadcn-default / not purple neon)

HardStuck’s client surfaces use a **broadcast scoreboard** look: deep ink panels, chalk type, amber signal accents, Archivo Black + IBM Plex Sans. Live totals animate with [@number-flow/react](https://number-flow.barvian.me/); layout motion uses [Motion](https://motion.dev/).

**Rejected:** generic Inter/zinc SaaS cards, purple glow esports kits, cream+serif terracotta, full shadcn marketplace templates as the visual system.

**Why:** Phase 1 is a calculator-first product. Distinctive type and a ticket/scoreboard metaphor beat another dark dashboard clone; NumberFlow gives intentional motion without decorative noise.
